## Overview

`Log Analyzer & Visualizer` is a production‑ready Python package that parses plain‑text log files, extracts useful statistics and creates visual reports (PNG charts). 
It demonstrates modern Python practices:

* **Typed code** with `typing` and `pydantic`
* **Configuration** via `.env` and `config.yaml`
* **Robust logging** and error handling
* **Unit tests** with `pytest`
* **Clear separation** of concerns (analysis, visualization, utilities)
